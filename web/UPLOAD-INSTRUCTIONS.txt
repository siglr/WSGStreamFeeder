WSG Stream Feeder 1.3.5 — upload into /otherdata/tools/ on WeSimGlide.org

1. Upload WSG-Stream-Feeder.zip.
2. Upload tools.css, feeder.js and assets first, then index.html, WSG-Stream-Feeder.html and .htaccess.
3. Upload WSG-Stream-Feeder.version.json LAST. This activates the release feed.

Merge the assets folder; do not replace/delete the entire server directory.
Enable cPanel's Show Hidden Files (dotfiles) to see .htaccess. If /otherdata/tools/
already contains an .htaccess, merge our block into it instead of replacing it.
The rules make pages and assets revalidate, and prevent stale feeder downloads.
One final hard refresh may be needed for previously cached pages to pick up the policy.
After uploading, verify that the page response includes Cache-Control: no-cache.

For website-only updates, run tools/prepare-web.ps1 in the project, then upload
the website files above. It automatically refreshes asset version tags. No ZIP
or signed version JSON upload is needed. Keep direct asset edits in web/assets too.
Retain the existing Standalone-DLSS-Glass-Cockpit-Refresh.html, its ZIP,
version JSON and other assets. The new index.html links to that existing page
and to WSG-Stream-Feeder.html, with a screenshot and description for each.

This instruction file does not need uploading. Nothing has been published automatically.
GitHub publishing does not activate the website update feed. Upload the ZIP and
website assets first, then the signed version JSON last.
Upgrading from v1.2: repoint OBS altitude.txt to altitude_asl.txt.

Do not upload signing keys, build tools, source folders, settings.json or Output.
Keep a protected Windows profile/system backup for the DPAPI release key.
See PUBLISHING.md in the source project for future releases.
