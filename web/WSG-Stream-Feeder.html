From download to overlay.

  1. Extract the full ZIP

    Choose a writable folder outside the simulator installation. Keep all the included files together, then open WSG Stream Feeder.exe.

    Install Microsoft’s .NET 8 Desktop Runtime (x64) if Windows says it is missing.

  2. Point OBS at the files

    Use Open output folder in the feeder. In each OBS text source, enable Read from file and select its matching .txt file.

    Set the fonts and positions in OBS.

  3. Start your flight

    The feeder connects automatically. Before telemetry arrives, the files display N/A.

    Use Minimize to tray to keep the window out of the way. Double-click its tray icon to reopen it.

Ready for the next session.

Choose Dark or Light to match your desktop. Your choice is saved. Official releases check for updates on startup and verify the download before installing it.

While connected to MSFS, an update waits for you. Finish your stream, then choose Restart to update or close and reopen the feeder. Your OBS files and settings are preserved.

A few useful details.

Is the speed indicated airspeed?

No. speed.txt contains ground speed in knots, matching StreamFlight’s output. Altitude uses indicated altitude in feet, with geometric altitude as a fallback. Heading is true, not magnetic.

Can I replace StreamFlight?

Yes, for these four OBS values. Repoint the four text sources to this feeder’s Output folder. The feeder does not depend on StreamFlight or reproduce its flight-plan and other overlay features.

Where are my settings?

Output defaults to an Output subfolder beside the EXE. For another location, copy settings.example.json to settings.json and edit OutputDirectory. Relative paths are resolved beside the application. Update the OBS file sources to match.

What happens if I close the feeder?

Exit stops telemetry and writes N/A to the four files. Minimize to tray keeps it running. If MSFS closes, the feeder waits for it to return.

Windows or antivirus warns about the download

The application does not currently carry an Authenticode publisher certificate. Its signed updates verify release authenticity, but they do not provide Windows publisher reputation. Keep protection enabled, check the exact detection and release hash, and contact WeSimGlide if the file is flagged.
